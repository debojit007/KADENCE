# Skills

KADENCE skills are reusable operating instructions for agents. They describe how an agent should perform a specialized behavior, independent of any single application surface.

## Skill Levels

```text
skills/shared/
```

Shared skills used across multiple agents.

```text
agents/{agent-name}/skills/
```

Agent-specific skills used by one agent.
